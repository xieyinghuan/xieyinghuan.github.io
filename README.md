# Yinghuan Xie's personal website

A lightweight, responsive holding page for a personal GitHub Pages website.

## Publish

1. Use the public repository `xieyinghuan/xieyinghuan.github.io`.
2. Put `index.html` in the root of the `main` branch.
3. In **Settings → Pages**, choose **Deploy from a branch**, then **main** and **/ (root)**, and save.
4. After deployment completes, the website is available at `https://xieyinghuan.github.io/`.

## Replace with the full website

Keep the repository and GitHub username unchanged to preserve the public address. Replace this holding page with your final website files, or configure the final site's build workflow to deploy to GitHub Pages in this repository.

This page has no external dependencies, tracking scripts, or build step.
